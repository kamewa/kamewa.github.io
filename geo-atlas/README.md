# 地理地圖集

國中地理課堂用的互動式地圖集：入口是一張寶藏地圖，九座透明按鈕對應九座 3D 小島，每座島再連到老師自己的教學頁面。
**離線使用**：整個資料夾複製到隨身碟，在教室電腦上雙擊 `index.html` 即可，不需要網路。
**線上版**：https://kamewa.github.io/geo-atlas/

> 這個倉庫是公開的，請不要上傳學生的個人資料或成績。4K 藏寶圖原圖（`assets/原圖備份/`）沒有放在這裡，請自行保存。

## 資料夾
| 位置 | 內容 |
|---|---|
| `index.html` | 地圖集入口（藏寶圖與透明按鈕） |
| `config.js` | 設定檔：每張藏寶圖的按鈕位置、名稱、連結（進入島用 `href`，遠航用 `goto`） |
| `assets/` | 藏寶圖圖片（1920／2560 兩種尺寸，4K 原圖放在 `assets/原圖備份/`） |
| `islands/` | 九座島的頁面：通論、地形、氣候、水文、人口、產業、交通聚落、區域發展、試煉 |
| `teaching/` | 老師自己的教學頁面，九座島各有一個子資料夾（`general`、`terrain`、`climate`、`hydro`、`population`、`industry`、`transport`、`regional`、`trial`） |
| `lib/` | 共用的 3D 程式庫（Three.js r128），請勿刪除 |
| `使用說明.txt` | 給使用者的完整說明 |

## 操作
- 滑鼠靠近某座島：浮現暖色光暈和島名，點下去進入；帆船上的「遠航」會移動到另一張藏寶圖。
- 在入口畫面按 **E** 鍵：進入校準模式，可拖曳按鈕、用滾輪調整大小，並複製新的設定貼回 `config.js`。
