# 版本紀錄

## v1.0（目前）
- 入口畫面改成老師自己製作的寶藏地圖，九座島是九個透明按鈕：滑鼠靠近浮現暖色光暈與島名，點下去進入；平常有呼吸般的小星光提示。
- 新增「遠航」按鈕：從第一張藏寶圖的帆船航向第二張藏寶圖，第二張圖的帆船可以回來。第二張圖的其他設定待討論。
- 九座島統一色調（修正偏黃的色偏，所有島使用同一組明暗與光線設定）。
- 地形島、氣候島：點水晶打開地形觀察系統（兩座島共用同一份頁面，存放在 `teaching/climate/`）。
- 試煉島：新的圓潤風格、有臉的火山；魔王出現後點魔王，在新分頁打開互動式評量系統（`teaching/trial/`）。
- 設定檔改成每張藏寶圖各有一組按鈕（`maps`），支援 `href`（進入）與 `goto`（遠航）。

## 更早的階段（未逐一保存，僅供參考）

- 離線資料夾與簡單版地圖集首頁；自己用程式畫的羊皮紙寶藏地圖版本（已改用老師的圖）。
