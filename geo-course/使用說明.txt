地理課程網站｜使用說明（骨架版）
==================================

【怎麼打開】
直接點兩下 index.html 就能用，不需要網路，也可以整個資料夾放進隨身碟。
（有網路時字型會比較漂亮；沒網路時會自動改用電腦內建的微軟正黑體。）

【資料夾裡有什麼】
index.html          網站入口（不用改）
css/style.css       全站外觀（積木風樣式）
js/app.js           網站功能（不用改）
js/site-data.js     ★ 網站設定：網站名稱、各洲、課程清單、按鈕位置
maps/               地圖圖片（世界與七洲是老師製作的地圖；arctic.svg 北極地區為暫用地圖）
maps/original/      老師上傳的原圖備份（網站不會讀取，只是保存）
lessons/            ★ 每一課的內容檔，一課一個檔案
lessons/img/        課程用圖片
tools/              工具程式（隱藏地圖的按鈕連到這裡）

【三層架構】
第 1 層 世界地圖（7 洲＋北極地區＋全球議題按鈕）→ 第 2 層 各洲地圖（課程按鈕）→ 第 3 層 課程頁
課程頁有「📖 複習模式」和「📺 簡報模式」，兩者用同一份內容自動產生。

【換成正式地圖】
1. 把圖片放進 maps 資料夾（建議 16:9，3840×2160）
2. 打開 js/site-data.js，把 map: 'maps/world.svg' 改成新檔名
3. 調整按鈕的 x、y（百分比：x 由左到右 0~100，y 由上到下 0~100）
4. 世界地圖的圓形按鈕大小：改 site-data.js 裡 world 的 pinSize（地圖寬度的百分比，目前 6）

【亞洲的入口按鈕與台灣分區地圖】
亞洲地圖上有三顆星光入口按鈕（台灣、中國、中亞），設定在 site-data.js 亞洲的 spots：
  href 填 '#/c/分區代號' 會進入下一張地圖；留空＝尚未設定（點了會提示）。
台灣分區地圖（id: 'taiwan'，地圖 maps/taiwan.webp）有 6 顆綠色呼吸光按鈕，設定在 buttons：
  label 改顯示文字；href 填 '#/c/代號' 進入下一層、填網址或檔案路徑會在新分頁開啟、留空＝尚未設定。
之後要讓課程出現在台灣地圖上，在課程的 on 裡加 taiwan: { x: .., y: .. } 即可。

【隱藏區與預留按鈕】
世界地圖左下（k 的位置）有一顆隱藏按鈕：看不見、不發光、游標不變，點到才會出現粉紅閃光並進入粉色隱藏地圖。
它不會出現在下方清單，也不算進「共 N 區」。設定在 site-data.js 的 id: 'x7'（size 是點擊範圍大小）。
隱藏地圖上有 12 顆工具按鈕（目前顯示 1～12），設定在 x7 的 buttons：label 改顯示文字、href 填工具網址或路徑，點擊會在新分頁開啟。
目前按鈕「氣候圖製作」連到 tools/climate/index.html（網站版，離線優先）；你的原始檔備份在同資料夾「原檔備份_氣候圖製作.html」，未改動。
氣候圖工具的「網頁嵌入碼」網址，會自動使用 site-data.js 最上方的 publishedUrl；網站搬家時只改那一行。
按鈕「地形觀察」連到 tools/terrain/index.html（網站版，完全離線可用）；你的原始檔備份在同資料夾，未改動。
網站版只在檔案最後加了一段「自動載入課程地形模型」（有註解標明），其他程式沒動。

【3D 地形模型（配合課程）】
模型檔放在 tools/terrain/models/，一個模型一個 .js 檔（內含高度資料、標籤、說明）。
網址 tools/terrain/index.html#model=au-landform 會直接開啟該模型；加上 &mode=weather 會直接進入「地形雨」。
課程內容檔的概念卡可加 models，就會出現綠色「開啟 3D 地形」按鈕（複習模式與簡報模式都有）：
  models: [{ id: 'au-landform', label: '澳洲地形：由東向西' },
           { id: 'au-landform', mode: 'weather', icon: '🌧️', small: '3D 地形雨', label: '大分水嶺與東南信風' }]
目前模型（共 14 個）：
  歐洲：eu-landform 歐洲地形／alps-u-valley 阿爾卑斯冰河地形／norway-fjord 挪威峽灣／ria-coast 谷灣
  俄羅斯：ru-landform 俄羅斯地形
  北美洲：na-landform 北美洲地形／young-vs-old 年輕高山 vs 古老山地
  中南美洲：sa-landform 南美洲地形
  大洋洲：au-landform 澳洲地形／nz-south-island 紐西蘭南島／nz-milford-sound 米爾福德峽灣
  兩極：arctic 北極地區／antarctica 南極洲／coast-sea-rise 海水面上升
從課程按鈕開啟的模型是「觀察模式」：學生只能旋轉、縮放、自動展示、切換設色，以及該模型需要的觀察工具
  （剖面切割／海平面／地形雨的播放、暫停、重播）；改地形、沙盒、拍照列印、存檔匯出都會隱藏。
  老師要完整控制：在上方說明卡的「標題」上按住 3 秒即可解鎖；重新整理就恢復觀察模式。
  每個模型顯示哪些觀察工具，設定在 tools/terrain/index.html 最後一段的 TOOLS。
  隱藏地圖的「地形觀察」按鈕（不帶模型）仍是完整原版功能。
模型是示意模型：依真實位置與海拔繪製，高度有放大；在工具裡按「隨機」或換地形就會離開模型，按「重新載入」可回來。
j、l、m 三個位置已預留在 site-data.js 的 world.reserved，之後新增區域時直接使用。

【開放一課】
1. 複製 lessons/ne-asia.js，改成新檔名（例如 lessons/se-asia.js）並改寫內容
2. 在 js/site-data.js 找到那一課，把 status: 'soon' 改成 status: 'open'

【課程內容檔可以用的段落】（參考 lessons/n-america.js）
intro      開場想一想
goals      學習課題
sections   分節（3-1、3-2…），每節可放 concepts 概念卡、think 想一想、quiz 學習check、can 我能…
  概念卡可加：points 條列、grid 小卡、image 單張圖、images 多張圖
myths      常見迷思　explore 影片／工具連結　checklist 自我檢核
簡報模式中，「想一想」和「學習check」按一次下一張先揭曉答案，再按一次才換頁。

【簡報模式快捷鍵】
→ / 空白鍵 / PageDown：下一張（簡報筆也可以用）
← / PageUp：上一張
Home / End：第一張 / 最後一張
F：全螢幕　N：講者備忘　T：目錄　Esc：關閉面板

【提醒】
網站放上 GitHub 會公開，請不要放學生姓名、成績等個人資料。
講者備忘學生也看得到，請不要放答案。
