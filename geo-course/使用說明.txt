地理課程網站｜使用說明（骨架版）
==================================

【怎麼打開】
直接點兩下 index.html 就能用，不需要網路，也可以整個資料夾放進隨身碟。
（有網路時字型會比較漂亮；沒網路時會自動改用電腦內建的微軟正黑體。）

【網站主視覺】
左上角是老師自製的「和」字印：images/logo-he.png（瀏覽器分頁小圖示是 images/favicon.png）。
換圖：把新圖放進 images 資料夾，改 js/site-data.js 的 logoImage 那一行。原圖備份在 maps/original/和字印_原圖.png。

【資料夾裡有什麼】
index.html          網站入口（不用改）
css/style.css       全站外觀（積木風樣式）
js/app.js           網站功能（不用改）
js/site-data.js     ★ 網站設定：網站名稱、各洲、課程清單、按鈕位置
maps/               地圖圖片（世界與七洲是老師製作的地圖；arctic.svg 北極地區為暫用地圖）
maps/original/      老師上傳的原圖備份（網站不會讀取，只是保存）
lessons/            ★ 每一課的內容檔，一課一個檔案
lessons/img/        課程用圖片
tools/              工具程式（隱藏地圖的按鈕連到這裡）

【三層架構】
第 1 層 世界地圖（7 洲＋北極地區＋全球議題按鈕）→ 第 2 層 各洲地圖（課程按鈕）→ 第 3 層 課程頁
課程頁有「📖 複習模式」和「📺 簡報模式」，兩者用同一份內容自動產生。

【換成正式地圖】
1. 把圖片放進 maps 資料夾（建議 16:9，3840×2160）
2. 打開 js/site-data.js，把 map: 'maps/world.svg' 改成新檔名
3. 調整按鈕的 x、y（百分比：x 由左到右 0~100，y 由上到下 0~100）
4. 世界地圖的圓形按鈕大小：改 site-data.js 裡 world 的 pinSize（地圖寬度的百分比，目前 6）

【亞洲的入口按鈕與台灣分區地圖】
亞洲地圖上有六個分區入口（台灣、中國、中亞、東北亞、南亞、西亞與北非；其中「中亞」直接進入課後閱讀「中亞五國」，lessons/central-asia.js），是實心底色的膠囊按鈕（左邊圖示、右邊「›」），和白底的課程按鈕區分，
  文字固定顯示、不晃動。設定在 site-data.js 亞洲的 spots：href 填 '#/c/分區代號' 會進入下一張地圖；留空＝尚未開放（顯示 🔒，點了會提示）。
台灣有三張分區地圖，用切換按鈕（kind: 'switch'）互相切換：
  台灣（自然）id: 'taiwan'，地圖 maps/taiwan-nature.webp，6 顆綠色呼吸光課程按鈕（自然地理課程）
  台灣（人文）id: 'taiwan-human'，地圖 maps/taiwan-human.webp，6 顆琥珀色呼吸光按鈕（人文課程）：1「人口成長與分布」→ 課程（一下第1章，lessons/population.js）；2「人口組成與族群文化」→ 課程（一下第2章，lessons/ethnic.js）；3～6 尚未設定

【雙語（繁中／English）】
網站右上角有「繁中｜English」切換鈕；選擇會記在瀏覽器裡，換頁也維持同一種語言。
分享給學生時，網址加 ?lang=en（例：https://kamewa.github.io/geo-course/?lang=en）會直接打開英文版；?lang=zh 是中文版。
・英文寫法：國中生讀得懂的簡易英文（短句、常用字），重要名詞後面附中文，例如 monsoon（季風）；英文頁面中的中文附註會以淡色顯示。
・講者備忘（簡報模式的 📝 備忘）保留中文，給老師上課用。
・老師自己的地圖圖片上的文字維持中文；網站名稱（左上角）也先維持中文。
・檔案位置：
  js/i18n.js：切換語言的程式（一般不用改）
  js/site-data.en.js：洲、分區地圖、課程、地圖按鈕的英文名稱（新增課程或按鈕時在這裡補英文）
  lessons/en/課程代號.js：英文版課程內容（和中文課程檔同樣格式）；某一課沒有英文版時，英文模式會顯示中文並提示「English version coming soon」
  lessons/img/en/：英文版說明圖（和 lessons/img 的中文圖同檔名）
  tools/climate/index.html：英文模式打開時，氣候圖上的標示（氣溫、降水量、類型、特徵）自動換成英文
  tools/terrain/i18n-en.js：3D 地形模型的英文標題、提示、地名標籤與工具按鈕文字（網址帶 &lang=en 才會載入）
・簡報模式：英文較長時，超出投影片底部的內容會自動縮小到放得下（沒有超出的投影片不受影響）。
・原則：之後新增的課程，都會同時做好英文版（課程內容、說明圖、氣候圖、3D 模型標籤）。

【城市氣候圖（老師的氣候圖工具）】
課程概念卡的 grid 小卡可以加 tag 和 chart，就會出現「📊 看氣候圖」按鈕，點了會用 tools/climate 的氣候圖工具彈出該城市氣候圖。
  例：{ icon: '🏜️', title: '熱帶沙漠', text: '…', tag: '開羅', chart: { city, type, feature, minTemp, maxPrecip, temps:[12個月], precips:[12個月], source } }
  各城市逐月月均溫、降水量與資料來源都寫在課程檔的 chart 裡。
  刻度原則（方便學生比較高低）：絕大多數城市固定為 氣溫 -40～40℃、降水 0～400mm，左右格線對齊（每格 10℃＝50mm）。
  ・降水超過 400mm 的城市：降水只往上多加到下一個整百（例：414→500、830→900），氣溫軸依比例往上延伸，超過 50℃ 不顯示數字。
  ・極低溫城市（月均溫低於 -40℃）：氣溫軸往下延伸到 -50、-70 等，降水仍每格 50mm。
  ・特殊多雨城市（超過 1000mm，如乞拉朋吉）：用特別刻度（0～3200mm）。
  ・氣候圖工具（tools/climate）已會自動依此原則延伸氣溫軸；手動輸入「降水上限」500 也會自動畫出對應刻度。
原則：課本有氣候圖、或課程介紹到的地區主要城市，都要放氣候圖按鈕；有對應地形的課程都要放 3D 地形模型按鈕。

【隱藏區與預留按鈕】
世界地圖左下（k 的位置）有一顆隱藏按鈕：看不見、不發光、游標不變，點到才會出現粉紅閃光並進入粉色隱藏地圖。
它不會出現在下方清單，也不算進「共 N 區」。設定在 site-data.js 的 id: 'x7'（size 是點擊範圍大小）。
隱藏地圖上有 12 顆工具按鈕（目前顯示 1～12），設定在 x7 的 buttons：label 改顯示文字、href 填工具網址或路徑，點擊會在新分頁開啟。
目前按鈕「氣候圖製作」連到 tools/climate/index.html（網站版，離線優先）；你的原始檔備份在同資料夾「原檔備份_氣候圖製作.html」，未改動。
氣候圖工具的「網頁嵌入碼」網址，會自動使用 site-data.js 最上方的 publishedUrl；網站搬家時只改那一行。
按鈕「地形觀察」連到 tools/terrain/index.html（網站版，完全離線可用）；你的原始檔備份在同資料夾，未改動。
網站版只在檔案最後加了一段「自動載入課程地形模型」（有註解標明），其他程式沒動。

【3D 地形模型（配合課程）】
模型檔放在 tools/terrain/models/，一個模型一個 .js 檔（內含高度資料、標籤、說明）。
網址 tools/terrain/index.html#model=au-landform 會直接開啟該模型；加上 &mode=weather 會直接進入「地形雨」。
  其他模式：&mode=convection 對流雨、&mode=frontal 鋒面雨；地形雨可再加 &wind=SW 指定風向（N、NE、E、SE、S、SW、W、NW）。
  課程概念卡的 models 可寫 { id: 'taiwan-rain', mode: 'weather', wind: 'SW', label: '夏季西南季風' }。
課程內容檔的概念卡可加 models，就會出現綠色「開啟 3D 地形」按鈕（複習模式與簡報模式都有）：
  models: [{ id: 'au-landform', label: '澳洲地形：由東向西' },
           { id: 'au-landform', mode: 'weather', icon: '🌧️', small: '3D 地形雨', label: '大分水嶺與東南信風' }]
目前模型（共 29 個）：
  歐洲：eu-landform 歐洲地形／alps-u-valley 阿爾卑斯冰河地形／norway-fjord 挪威峽灣／ria-coast 谷灣
  東北亞：ne-asia-landform 東北亞地形（日本群島與朝鮮半島，可開地形雨：冬季西北季風）
  西亞：w-asia-landform 西亞地形（三大高原與兩河平原，可開地形雨：冬季西風）
  南亞：s-asia-landform 南亞地形（印度半島，可開地形雨：夏季西南季風）
  中亞：ca-landform 中亞地形（天山、帕米爾、裏海與沙漠，可開地形雨：西風）
  漠南非洲：ssa-landform 漠南非洲地形（高原、盆地、東非大裂谷，可開地形雨：東南信風）
  俄羅斯：ru-landform 俄羅斯地形
  北美洲：na-landform 北美洲地形／young-vs-old 年輕高山 vs 古老山地
  中南美洲：sa-landform 南美洲地形
  大洋洲：au-landform 澳洲地形／nz-south-island 紐西蘭南島／nz-milford-sound 米爾福德峽灣
  兩極：arctic 北極地區／antarctica 南極洲／coast-sea-rise 海水面上升
  臺灣：taiwan-strait 冰河時期的臺灣海峽／taiwan-landform 臺灣地形／five-landforms 六種地形比一比／ridge-valley 等高線山脊與河谷
         coast-sand-rock 沙岸與岩岸／continental-island 大陸島成因／taiwan-coasts 臺灣的四段海岸
         taiwan-rain 臺灣的三種降雨（地形雨・對流雨・鋒面雨）
         taiwan-rivers 臺灣的河川：東西分流／watershed 水系、流域與分水嶺（示意）
從課程按鈕開啟的模型是「觀察模式」：學生只能旋轉、縮放、自動展示、切換設色，以及該模型需要的觀察工具
  （剖面切割／海平面／地形雨・對流雨・鋒面雨的播放、暫停、重播）；改地形、沙盒、拍照列印、存檔匯出都會隱藏。
  老師要完整控制：在上方說明卡的「標題」上按住 3 秒即可解鎖；重新整理就恢復觀察模式。
  每個模型顯示哪些觀察工具，設定在 tools/terrain/index.html 最後一段的 TOOLS。
  隱藏地圖的「地形觀察」按鈕（不帶模型）仍是完整原版功能。
模型是示意模型：依真實位置與海拔繪製，高度有放大；在工具裡按「隨機」或換地形就會離開模型，按「重新載入」可回來。
j、l、m 三個位置已預留在 site-data.js 的 world.reserved，之後新增區域時直接使用。

【開放一課】
1. 複製一個現有的課程檔（例如 lessons/coast-island.js），改成新檔名（例如 lessons/se-asia.js）並改寫內容
2. 在 js/site-data.js 找到那一課，把 status: 'soon' 改成 status: 'open'

【課程內容檔可以用的段落】（參考 lessons/n-america.js）
intro      開場想一想
goals      學習課題
sections   分節（3-1、3-2…），每節可放 concepts 概念卡、think 想一想、quiz 學習check、can 我能…
  概念卡可加：points 條列、grid 小卡、image 單張圖、images 多張圖
myths      常見迷思　explore 影片／工具連結　checklist 自我檢核
簡報模式中，「想一想」和「學習check」按一次下一張先揭曉答案，再按一次才換頁。

【簡報模式快捷鍵】
→ / 空白鍵 / PageDown：下一張（簡報筆也可以用）
← / PageUp：上一張
Home / End：第一張 / 最後一張
F：全螢幕　N：講者備忘　T：目錄　Esc：關閉面板

【提醒】
網站放上 GitHub 會公開，請不要放學生姓名、成績等個人資料。
